# v0.8.0-alpha.5：门闸素材分类与四款外观

门闸按类型、颜色整理，每个颜色独立保留，普通门闸排完各颜色后再排列怪物门闸。每色一张折叠卡，展开仅显示：

1. 1格 · 外观朝下。
2. 1格 · 外观朝上。
3. 1.5格 · 外观朝下。
4. 水平横向门。

原版红色符文门缺少已验证的横向模型，因此该项直接隐藏。原生目录为6个颜色／类型分组、23款可用基础外观，不再为响应参数或细微色值差异增加素材卡。

- 图卡、放置提示与属性配置改用中文类型、颜色及形态名称。折叠、展开、搜索、收藏及最近使用继续可用；旧原生预设键与工程记录不改写。
- 展开箭头只负责折叠；卡片齿轮负责频道、高度及开合参数，互不抢占。每款形态分别记忆放置设置，并兼容读取上一版偏好。
- 外观朝上／朝下由原生模型区分，开合反转只修改机制。六向箭头和R旋转保留，反转不再替换外观模型。
- 门闸展开卡不再被短素材面板压扁，保留真实模型缩略图及两行形态名称。

## 验证与限制

类型检查通过。完整274项通用与原生读取／写回／构建回归通过；无原游戏环境179项通过、95项原生检查明确跳过。分类与外观修复的11项重点回归通过。另以32项独立Electron自动检查验证颜色排序、四款展开、收起重开、真实缩略图、选中高亮、频道参数、快捷槽、R旋转及两种工作区临时试玩；测试使用模拟启动，不运行原游戏。覆盖1366×768、1920×1080及125%缩放。

提供Windows x64安装版、ZIP和SHA-256清单。游戏内开合动画、角色联动与安装体验仍由用户实测；不关闭现有窗口、不操作正式存档。

## 用户检查

保存工程后重启新版。素材库搜索门闸，检查普通门闸颜色顺序及其后的怪物门闸；展开任一颜色检查四款外观，收起再打开；点击图卡齿轮调整频道与反转，确认外观不被换掉。放置、保存重开后，在隔离试玩中对照方向。
