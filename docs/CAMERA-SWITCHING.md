# 分屏定位、镜头构图与游戏切换

## 先区分两个入口

- **自由定位**：把编辑视角移到某一块范围，方便搭关；不会保存游戏镜头。
- **编辑镜头**：进入主画布的镜头构图状态，修改当前原生镜头的参数。

在选择工具下，单击分屏中的地面或空白处，边界高亮后点击“编辑镜头”；也可以双击该屏。点到物件时仍先选择物件，拖动空白处仍可框选。关闭分屏边界后不进行虚拟分屏选择。

规则分屏共用一套取景参数，按网格平移。选中第 (1, 0) 屏，是从这屏查看和修改整套镜头，不是创建“进入这屏时调用另一台摄影机”的触发器。退出镜头编辑恢复原自由视角。静态构图不验证游戏的动态过渡、特殊区域限制、探索范围自适应或额外视角解锁。

自由定位按完整规划列出分屏，包括没有地形的屏；例如 3 列 × 2 行列出 6 屏。自动模式覆盖设计范围内的整套网格，不再只列有地形的屏。导航旁显示总屏数，超过 500 屏时分页，继续向后可到达最后一屏。定位高度使用当前编辑高度，显示切换不修改原生地形或分屏参数。

当前默认原生分屏支持 **G → Y** 调整南向距离、**G → Z** 调整原生高度、**R → X** 调整俯仰。横向中心由每屏网格确定，整套网格可在布局模式用中央平移柄或位移输入移动。中键只浏览各屏，不改变网格。默认分屏按距离重算姿态，不能把普通物件旋转直接当作 R 的 Y/Z 写回；单场景镜头不统一锁这些轴，特殊动态镜头保留其引用与限制。

布局只绘制配置的横纵屏数。整体移动不改地形和循环范围，自动布局在移动提交后固定当前屏数；取消及撤销可恢复自动状态。横纵数量是编辑规划，角色走出矩形后仍使用原生网格取景，不自动改为总览或另一台镜头。

数字参数在当前输入框即时预览并自动提交；同一段连续输入合并撤销。游戏中的分层界限与摄影机高度不是一个参数：原作可根据角色所在玩法层选择镜头，当前编辑器保留这些导入配置，尚无完整的“角色 Z 超过某值 → 指定镜头”创建向导。

## 多台镜头如何在游戏中使用

1. **规则切屏**：设置网格起点和每屏格数，角色跨屏时游戏自动平移取景。
2. **不同高度的玩法镜头**：原版通过世界层及主镜头选择处理。保留导入关的层边界、主镜头和限制区域。不要把同层新增多台主镜头理解成任意房间的独立角度触发。
3. **额外视角卷轴**：在素材库“世界”找到“视角卷轴”（View_Giver）。原生 `viewpoint_name` 与辅助镜头的 `entity_name` 相同，例如 `side` 或 `top`；辅助镜头的“参与原生主镜头选择”关闭。游戏获得该视角后，通过游戏的切换视角操作使用，按键以游戏键位设置为准。
4. **地图总览**：卷轴的 `map_overview_id` / `map_overview_id_2` 关联总览镜头。总览与额外侧视／俯视不是同一个配置字段。

镜头面板的“游戏中如何切换镜头”列出当前加载内容里的卷轴与镜头对应关系。当前支持读取、保留和通过原生属性调整这些字段，尚无一键建立完整卷轴组合的向导。镜头改名时也要同步卷轴的视点名称，否则名字关联会失效。

`camera_z_lock` 的目标是确定观察高度的物件，目标不必是摄影机。其附加浮点参数参与区域选择，不是要锁定的 Z 数字。不能将它作为任意指定摄影机的房间触发器。

## 本次修正和验证界限

按 Steam Build 26466613 的原生结构及构造逻辑修正省略值：FOV 35°、高度 19、南向距离 12、平移速度 0.35、观察点南向偏移 0。空白关已经显式保存的 45°不改写。显式值始终优先。

分屏预览读取观察点南向偏移，窄画幅按原生的 16:9 水平视野规则换算；“框住当前分屏”只适应当前屏内的玩法范围。未修改原版记录保持原样。

自动检查覆盖界面入口、取消、选屏不修改工程、字段读写及构图数学；本轮没有启动游戏。多高度自动选择、卷轴获取与切换、区域过渡及最终画面由用户在隔离测试战役中核对。
