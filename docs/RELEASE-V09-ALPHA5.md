# v0.9.0-alpha.5：直接选屏与镜头入口澄清（仅本地）

- 单击分屏的地面或空白处显示高亮和“编辑镜头”，双击直接进入该屏构图。物件、放置、框选和鼠标导航保持优先，取消不提交编辑。
- 导航里的“分区”改名“自由定位”，不再将编辑定位呈现为游戏镜头；原生镜头导航与镜头编辑共用静态构图计算。
- 框住分屏只适应当前屏，不再按整关范围把镜头拉远。补齐原生观察点南向偏移读取及白名单写回、窄画幅换算和 Camera_Control 缺省值。
- 多层镜头不再因为场景只有一名角色就全部套用同一高度；不将 camera_z_lock 的附加参数错误解释为观察高度。
- 镜头面板加入原生切换说明与卷轴关联列表；View_Giver 改称“视角卷轴”。[完整说明](CAMERA-SWITCHING.md)。

检查发现旧“分区1、分区2”导航只做自由定位，先前界面没有说明差异，容易与游戏镜头混淆。最新运行包已确认启用 4×6 分屏，FOV 显式为 45°；缺省值错误不是这次包的已确认根因。

本版不新增任意房间触发镜头或一键卷轴向导，不宣称静态参考完整模拟原生相机。原生切换、动态自适应和游戏内构图仍需用户实测。本轮不启动游戏，不触及正式存档，不上传 GitHub。
