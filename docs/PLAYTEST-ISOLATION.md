# 独立试玩：实现与验证范围

v0.8.0-alpha.2，2026-11-14，Steam Build 26466613。

## 当前行为

常规工作台顶栏选择单关、临时关卡组或完整工程，再点试玩。完整原版世界工作区可试玩当前小关或整个原版世界。确认窗口默认继续兼容档；明确输入名称新建才增加目录。取消不产生存档，也不部署或启动。修改不兼容时保留旧档，用户可以另建，或在确认窗口明确选择备份后重置旧档；后者沿用原ID、名称并重新绑定当前修订。

游戏仍在运行时不能部署和重置。不会关闭现有窗口。显示声音设置可从原版只读复制，或保留测试中的独立调整；启动不强制窗口化、分辨率或音量。

## 路径与边界

仅对当前检查过的游戏程序创建受管启动程序，替换只读数据段内唯一的25字节存档目录名，使用等长 ASCII 名 SStar_Editor_加12位档案ID。原文件保持不变，不发布游戏程序。程序哈希、字节结构和只读段必须符合检查；未知游戏程序拒绝运行，不猜偏移。

通过 Windows SavedGames 已知文件夹接口得到真实父路径。独立目录联接只允许指向当前工作区已登记档的 saves；有同名外部目录或链接时拒绝覆盖。正式目录 Order of the Sinking Star 不移动、不联接、不修改。测试档名称在编辑器显示，原游戏可能显示内部战役标识。

每次启动验证工程、范围、来源与修改修订，已有档不清空历史。旧共享 launch/worldLaunch/worldReset 入口继续拦截；新的 runLaunch/nativeRunLaunch 必须显式选择或新建隔离档。副本中的原始程序保留为不可直接启动的 .disabled 文件，只有校验过的独立启动程序会被执行。

这是游戏存档路径隔离，不是 Windows 权限沙箱。不要手动运行旧共享副本，也不要自行改动隔离联接或启动程序。原版存档请在 Steam 原游戏查看；从 Steam 直接加载编辑器测试关卡仍暂缓。

## 已检查

- 已检查当前程序 SavedGames GUID 与目录拼接调用；独立程序只改等长目录名，源程序和文件其余字节不变。
- 实际独立启动后，载入列表只显示测试档的战役，没有正式战役；用户也确认了此观察。
- 已载入测试档，随后通过编辑器服务的完整校验、部署、命名档和启动链路进入16×16空白关，角色与出口正常显示。
- 对照启动前清单：正式存档105个文件的哈希、修改时间和文件集合未发现变化。
- 自动测试检查未知程序拒绝、目录冲突保留、重置后重新联接、重复启动不删历史、兼容档复用、控制字符拒绝及无选择时不启动。
- 独立 UI 回归检查确认打开、取消、不填名称、新建、重复继续，以及原版世界使用同一确认流程；UI 回归使用模拟启动，没有额外打开游戏。

## 尚未覆盖

没有进行全部关卡机制、完整世界循环／跨层／解锁的通关验收；游戏内重置／删除菜单和所有全屏、多显示器、音量组合未逐项操作。管理器的重置／删除只处理登记档并先备份。游戏更新后的程序需要重新检查隔离路径。

## alpha.3 临时试玩

临时会话在 workspace/temp-playtests 下，使用相同的原生目录隔离与唯一目录名；不会登记到永久测试档列表。游戏退出后，先保留独立显示声音设置，再检查目录归属与链接目标并清理临时进度。编辑器提前退出时在下次连接后、确认游戏未运行时处理遗留会话。未知目录和异常链接保留。独立设置跨临时／存档试玩共用；自动检查未代替游戏内退出流程实测。
