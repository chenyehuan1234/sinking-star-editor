# v0.8.0-alpha.3

本版修复门闸的原生参数一致性，增加临时试玩与按范围导出，并调整检查、装饰与属性入口。

- 试玩右侧下拉选择临时／存档方式，主按钮记住选择。临时进度使用专用隔离目录，不进入永久测试档列表；退出清理，异常遗留在下次连接且游戏退出后处理。独立显示声音设置保留。
- 撤销左侧导出图标：当前关、关卡组、整个工程；可编辑工程选文件位置，原生运行数据选目录。运行数据含完整基础包、必要资源别名、工程副本和 SHA-256 清单；不附游戏程序、存档，不自动部署。
- 工程检查使用虚拟滚动、固定双行条目、搜索与范围／严重程度筛选，点击定位并展开完整详情。没有地图入口是提醒，不阻止单关测试。
- 简洁模式保留装饰图标。用户装饰、原版布景、远景辅助分别控制；地形设计网格／原生材质独立。云层和灯光辅助默认隐藏，特殊材质以轮廓预览。修复背景解锁被显示更新覆盖。
- 场景物件支持全部／非装饰／装饰过滤；双击激活属性面板，F 聚焦。大地图入口保留双击进入小关。
- 原生门闸缺省 height 为1，旧界面错误显示2；显式1.5、2、3保留。目录预设标识兼容，缓存升级。属性标出默认／显式来源。
- R、操纵柄、属性朝向和组合旋转同步四元数与适用的原生角度字段。方向按钮按世界 +X/+Y/−X/−Y 显示当前状态。开合方向、横向安装、反向响应和外观分别解释。

## 验证范围

类型检查、通用测试、原生读取／写回／构建回归，以及独立 Electron 界面自动检查分别记录。界面检查覆盖1366×768、1920×1080、125%缩放、1500项检查列表、导出请求、临时试玩请求、属性激活和背景解锁。界面试玩使用模拟启动，不运行原游戏。

原生回归验证门闸高度与方向字段、区域旋转、单关导出重读与资源清单；临时目录测试验证设置保留、链接归属与清理。Windows包检查验证安装文件、ZIP、ASAR和校验值一致，并排除个人工程、游戏资源、存档及工作区。

本版未执行安装升级或游戏内机制操作。临时游戏退出流程、全屏声音体验、门闸开合动画、跨层阻挡、完整世界循环与进度仍须实机验收。可执行文件未签名。

## 用户验收

1. 保存工程，重启新版。在试玩下拉选择临时试玩，测试同一关两次，确认均从初始进度开始，永久档列表不增加，显示声音符合设置偏好。游戏正常退出后检查临时目录清理。
2. 导出当前关到中文路径，再导回编辑器；选择关卡组和整个工程分别导出。原生运行数据检查 manifest.json 与 design 工程，使用编辑器独立试玩验证，不覆盖 Steam 原安装。
3. 选择门闸，核对默认高度1；分别测试1.5／2／3、四方向、R旋转和属性朝向。保存重开、撤销重做后比较游戏结果。
4. 打开大量问题的工程检查并滚动、筛选、定位。隐藏原版布景后仍可在物件列表查找；显示、解锁、双击属性和删除撤销各验证一次。

旧 v3／v4 工程继续读取。正式战役和 Steam 原安装不参与验收操作。
