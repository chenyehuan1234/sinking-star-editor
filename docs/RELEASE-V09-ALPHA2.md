# v0.9.0-alpha.2：本地候选，尚未上传

中键单击、世界显示与辅助对象修复。按用户要求，本版本仅在本地检查、打包，不推送源码、不创建GitHub发布。

- 中键只在短促、未移动、没有其他按键的单击松手时取样。按下不取样，拖动、原点往返、画布外移动、滚轮导航及长按松手均不取样。右键与自定义导航保持。
- 大地图缩远继续请求原生物件与原始整数地形，不自动切换粗地形／入口代理；总览按钮只调整视角。仍按视野和Z范围读取，原生小关和入口关系不变。
- 装饰的三类显示默认关闭。旧版本导致误开启的显示值不自动带入新默认，其他高度过滤、锁定和物件设置保留；本版明确开启的选项继续记忆。
- 修复遗漏的辅助对象分类，包括 Shadow_Decal、Translucent_Shadow、无后缀 editorUI、cloud2 材质和 GAME_EX_CamControl 标记。默认不创建其场景模型；主动显示辅助时使用轮廓。不是按白色／黑色过滤，不隐藏正常玩法宝石或光束。
- 地形显示不再自动开启／关闭装饰。关闭装饰时保留设计地形；原作地面和墙体的外观也属于场景模型，查看原生外观需主动显示原版布景。指南新增两种显示的区别。

- 关卡搜索改为标题栏图标，默认收起，点击展开并聚焦搜索；收起后恢复完整目录，搜索词仍记忆。
- 场景物件优先显示作者名称；未命名装饰显示实际模型身份。单击高亮（包括锁定物件）、双击聚焦，画布选择同步滚动列表，必要时解除挡住目标的列表筛选。
- 装饰选项提供独立的碰撞地形锁、原版地形与布景锁；单个外观模型仍可用行内锁。原版大型地形外观可能是一个网格，不能当成逐格体素拖动。
- 原生水域不再依赖背景解锁：装饰关闭时可选择、拖动，只在未被地形覆盖的有效湿格命中。水域仍遵守自身的显示与锁定。
- 修复相机分区辅助刷新时解绑普通物件操纵柄的问题，移动提交后可继续拖动，无需重选。
- 工作区建立独立层叠上下文，布局菜单覆盖方向立方体、镜头三轴与浮动面板。

类型检查通过；通用测试195项通过、104项需原游戏而明确跳过；本机原生回归299项全部通过。真实Electron中键／显示检查27项、完整世界操作检查12项、物件列表与搜索16项、水域／操纵柄／菜单层级16项通过，覆盖短促单击、长按不取样、往返拖动、默认装饰关闭、按钮取消联动、切关材质及缩远保留原生模型。数据读写使用安装中的原生资源，界面试玩不启动真实游戏。
