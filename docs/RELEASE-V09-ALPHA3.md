## 用户实测

1. 进入空白关“编辑镜头”，中键抓取平移，G→Z 调高度，R→X 调俯仰；对齐 +Z 后继续操作，测试 Esc 和撤销。
2. 为物件和观察中心取点，用三轴微调后确认，保存重开；检查取消和撤销。
3. 切规则分屏，设置每屏宽高、取点／拖动起点，点选其他屏，再编辑整套镜头。游戏内跨屏切换、原生区域优先级和多高度效果由用户验收。
4. 导入复杂关先沿用原版；遇到未知观察高度按提示取点，不自动解除玩法引用。总览与玩法镜头分别检查。
