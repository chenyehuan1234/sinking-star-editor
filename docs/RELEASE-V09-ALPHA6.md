# v0.9.0-alpha.6：分屏、镜头与编辑交互累计更新

这是自上次公开的 **v0.9.0-alpha.1** 以来的累计测试版，包含此前仅在本地交付的 alpha.2～alpha.5，以及本轮布局、场景显示、水流和数字交互改动。下文按实际功能整理，不将历史检查结果冒充本版实机验证。

## 分屏与镜头

- 布局工具、常驻边界和自由定位共用起点、尺寸及横纵屏数。3×2 只显示六屏，包含空屏；定位按行列编号，不按地形高度生成重复的 Z0/Z1 条目。
- 布局中央提供 X/Y 平移柄及整体位移输入。拖动只更新本地预览，提交和规划数量作为一步撤销；自动布局移动时固定开始的屏数，取消恢复原状态。
- 默认原生分屏开放 G→Y 调南向距离、G→Z 调原生高度，R→X 调俯仰；修正原先只移动预览观察点的写法。其他轴按具体原生路径说明限制，单场景不统一锁轴。
- 横纵数量是编辑规划范围，不是游戏镜头限制。出界继续按原生网格取景；原作高度层和限制区域分别处理。当前保留原生分层配置，尚无自定义高度阈值切换向导。

## 显示与导航

- 区分逻辑地形、地形外观、普通装饰、环境效果及编辑辅助。读取完整原生可见性标记，并根据继承材质着色器分类。
- 云、烟雾、星云等载体默认不加载为实心球或竖板；主动查看时显示轮廓。正常玩法球体和发光物件保留，源记录不变。
- 全部已加载、可见水域默认显示流向，不依赖选择或水域编辑面板；保留高度过滤、地形遮挡和按水域缓存。
- 小关画布常驻返回大地图入口，恢复原世界视角及选择。装饰下拉支持外点和 Esc 收起，内部切换时保持打开。

## 数字输入

- 坐标、变换、镜头等支持的属性即时预览；完整数字短暂停顿后自动提交，保持输入焦点，不要求失焦或 Enter。
- 同一输入段的自动提交合并为一步撤销；频道也先预览关联，再提交原生参数。空白、负号等未完成输入不提交。
- 整数参数使用精确增减按钮和整数运算，保留 64 位频道，不通过浮点数增减。文字名称继续在完成输入时提交；新建水域、执行阵列等操作仍保留明确执行入口。

## 此前本地阶段一并发布的改进

### 鼠标、选择与物件列表

- 中键仅在短促、未移动的单击松手后取样；拖动、往返、长按、滚轮及画布外取消不再意外取样。
- 水域选择和移动不再依赖开启装饰或解除原版布景锁；只命中未被地形遮住的有效湿格。
- 修复移动物件后操纵柄消失，需要重新选中的问题；相机区域辅助刷新不再解除普通物件的操纵柄。
- 场景列表优先显示作者／用户名称，未命名模型显示岛屿、建筑、地砖等类别与资源身份；单击高亮、双击聚焦，画布选择同步滚到列表对应行。
- 关卡搜索收起为标题栏图标，按需展开并聚焦；原有搜索、分组、滚动和选中记忆继续保留。

### 镜头与可视化工具

- 中键抓取方向统一；镜头移动／旋转可用 G/R 与轴约束，三轴箭头和旋转环分别显示，减少方向对齐后的遮挡。
- 位置、观察中心、控制区域以及分屏／循环起点支持画布取点和三轴微调，确认一步撤销；取消、失焦和越界释放不产生多余操作。
- 游戏镜头与分层区域合并到同一面板；默认展示玩法镜头，原版总览、辅助镜头和控制区域放在高级管理中，旧停靠布局保留有效位置。
- 分屏边界在自由画布直接可见；单击分屏显示编辑入口，双击进入对应屏的构图，普通物件选择与框选优先。
- “自由定位”与游戏构图明确区分，退出镜头编辑恢复自由视角；规划数量不更改原生存档兼容身份。
- 可画矩形设置每屏大小和循环 XY 边界；预览、确认、取消和撤销共用一致范围，循环操作保留原有 Z 信息。
- 修正原生相机省略值、观察点南向偏移、窄画幅 FOV 换算，以及多高度镜头被错误归到同一高度的问题；框住分屏只适应当前屏内内容。
- 视角卷轴按原生名称关联辅助侧视／俯视，总览通过镜头 ID 关联。新增面板说明和关联列表；目录缓存更新显示文字而不改变预设身份。

### 世界显示与工作区

- 大地图缩远后继续显示原始地形和原生物件，不自动替换为难以定位的粗缩略代理；仍按视野与高度范围加载。
- 地形设计显示和装饰显隐取消联动，补齐阴影、无后缀编辑图标及特殊环境分类；本轮进一步拆分地形外观、普通装饰和效果载体。
- 修复布局菜单被画布方向立方体或镜头控制器遮挡的问题；保留面板停靠、浮动、折叠及本机布局记忆。
- 更新内置分区指南、当前快捷键说明、原生镜头解释和人工验收步骤。

## 已知限制与兼容说明

- 默认原生规则分屏依赖房间中心及距离参数，不把普通物件的任意旋转当成可运行的镜头配置；单场景与动态／辅助镜头按各自原生路径处理。
- 自定义“角色超过某个高度就切到指定镜头”的完整创建向导尚未实现；原版已有高度层与限制记录继续保留。
- 网格横纵数量只限定编辑规划与显示，不自动限制游戏中的镜头范围；循环、玩法边界和镜头限制是不同配置。
- 原版逻辑体素与美术外观分开。修改碰撞不会自动雕刻整块岛屿模型；特殊环境效果提供轮廓，不宣称完整复现原作渲染。
- 继续兼容已有 v3／v5 编辑工程和原版基础数据；不附带游戏、个人工程、缓存、存档或试玩副本。未知游戏程序版本仍遵守既有隔离验证限制。
- 安装程序和可执行文件仍未签名；安装向导、升级手感以及游戏内动态切换、跨层、卷轴获取、机关操作需用户实测。

### 建议用户优先验证

1. 新建六屏布局，整体平移后撤销，保存重开；进游戏跨屏核对构图。
2. 保持数字框焦点修改坐标、频道、镜头参数，点击整数增减，再检查一步撤销与重开。
3. 原版场景开启普通装饰，确认不再出现实心云球或星云竖板；查看多片水域的默认流向。
4. 从大地图进入小关再返回，检查位置与选择恢复；原生多高度、限制区域、卷轴获取与切换单独做实机对照。
