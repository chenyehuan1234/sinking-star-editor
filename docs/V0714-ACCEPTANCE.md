本轮提供地形表面格线、地形右键单格删除、关卡行复制/删除、实时倒角方向立方体及镜头三轴控制器。

- 类型检查与构建通过。
- 原生环境：Steam Build 26466613。224 项测试通过，包含可离线执行的通用测试和需要自有原游戏的原生集成测试。
- 倒角几何覆盖六主面、八切角、十二切棱及各表面法线；镜头变换保留中心与距离，拒绝原生无法保存的方向。
- 原生集成验证：方向对齐、三轴配置经 JSON 保存重开、原生字段写入、二进制序列化与解析后保持有效。
- 独立 Electron 界面检查通过 46 项，包含真实鼠标拖动 Z 箭头和旋转环、撤销/取消、格线不重建、单格及矩形擦除、关卡复制/删除、立方体同步和两控件同时显示。
- 检查 1920×1080、1366×768 与 125% 缩放。独立测试工作区，不关闭用户编辑器或游戏。

## 操作验收步骤

1. 打开空白小关，确认顶面和侧面都有格线；分别切换地形格线和固定辅助网格，两者独立。
2. 地面/墙体工具中右击删除一格，右拖擦除矩形；空白处右拖旋转。普通选择中右击也能删一格；普通素材放置时右击取消。撤销恢复。
3. 点击选中关卡行右侧的复制图标，编辑副本并确认原关独立；删除副本，再撤销。关联入口跟随既有事务恢复，锁定入口阻止删除。
4. 转动自由镜头，确认倒角立方体同步；分别点主面、切角面、切棱面对齐。旋转到另一侧，可点击对应背面方向。
5. 进入编辑镜头，确认立方体仍在。拖动红 X、绿 Y、蓝 Z 箭头及旋转环；检查平移、绕取景中心旋转、角度提示、一步撤销及取消。保存重开核对构图。
6. 在分屏/总览镜头检查禁用轴和方向的解释。动态镜头保留原关联，不自动解锁。

## 验证范围

界面截图与自动输入检查已完成；尚未进行用户手感验收、真实安装/卸载升级测试或游戏内试玩。本轮不把原生构建成功当作游戏运行、机制或通关验证。

原生相机仍要求位于取景中心上方、保持无侧倾；分屏保持南向。主面六个方向在自由编辑中均可用；游戏镜头中不能精确写回的方向置灰。方向键继续用于物件微移。

安装版和 ZIP 均未签名。原游戏资源由用户自己的安装目录只读加载，发布包不含关卡包、个人工程、存档或试玩副本。
