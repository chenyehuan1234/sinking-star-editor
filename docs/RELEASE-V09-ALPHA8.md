# v0.9.0-alpha.8：镜头工作台、卷轴关联与取景修复

本次公开测试版包含 alpha.6 之后的镜头编辑与交互改动。提供 Windows x64 当前用户安装程序、完整免安装 ZIP 和 SHA-256 校验文件；无需 Node.js。原游戏资源从用户的 Steam 安装读取，分发包不包含原游戏、工程或个人存档。

## 镜头工作台与直观取景

- 镜头栏按“本关画面规则 → 镜头清单 → 当前取景 → 特殊控制区域”组织，只保留一份清单，移除属性页、世界属性和高级管理中的重复编辑器。
- 清单以用途标签区分正常游玩、额外视角和地图总览；支持名称／用途／ID 搜索、选中行复制与删除。单击选择，双击直接进入对应镜头取景。
- 数字收在默认折叠的精确参数，名称、用途、锚点及卷轴位于关联与原生设置；特殊控制区域单独折叠，不与相机混排。未识别区域只读保留。
- 按工程、场景记住折叠、选中、搜索与面板滚动。显示时保留三位小数，不改变未编辑的原始精度。
- 结束按钮统一为“完成镜头编辑”；完成或 Q 恢复原自由编辑视角。查看和切换不新增工程操作。
- 分屏摘要采用独立横向统计与下一行布局按钮，窄面板不再逐字挤成竖排。
- 分屏边界移入画布上方图标栏，升级后默认开启，简洁模式也可使用，之后记住本机选择。

## 普通相机、分屏和导航的一致性

- 属性页编辑镜头和镜头清单编辑当前相机对象，分屏卡片编辑所选屏；普通入口不继承旧分屏坐标，不擅自切换游戏运行方式。
- 普通相机采用自身原生位置、朝向、目标引用与 FOV。普通世界姿态与分屏共享姿态分别保留，调整普通相机不清除分屏设置。
- 修正自由编辑导航下拉误用分屏计算的问题：普通／辅助／总览与对应编辑入口共用世界姿态，分屏构图导航与所选行列共用相同取景。总览不再临时换成另一套俯视角度，分区导航也不再仅框住一个矩形。
- 导航与编辑采用相同的位置、观察点、上方向、视角与构图比例；仅查看不写入工程，拖动后可继续自由导航。
- 进入分屏取景继续显示黄线和当前屏高亮；有限布局选择图可点击或用方向键切屏，空屏、负坐标及非零起点保持一致。
- 同套分屏共享姿态，其他屏按网格平移；切屏同步画面、标题与属性，不构建、不增加撤销记录。
- 选中分屏即显示整套 X/Y 移动柄，无需 W，拖动、切屏和撤销后保留。卡片和取景选择图保留移动边界入口，移除独立浮动按钮及编辑整套镜头按钮。
- 移动布局只改变网格起点，保留屏数、尺寸、地形、物件和循环范围；一次拖动一步撤销，取消、失焦与视口外释放不提交。

## 六轴调整与原生写回

- 普通、分屏与总览镜头均可进行 XYZ 平移和旋转，移除按类型锁轴和 5°～89° 俯角钳制；方向立方体保留 26 个对齐方向。
- 中键平移、右键环绕、滚轮调整距离；G/R 后按 XYZ 设置世界轴约束。
- 用完整位置、观察点和上方向保存姿态，保留侧倾。拖动、滚轮、对齐、属性与框住范围操作采用同一份姿态。
- 普通相机使用可选 nativePose 世界姿态，分屏使用 pose 共享姿态。工程格式兼容读取；沿用模板时写回普通相机，保留模板 Settings 和网格记录。
- 连续提交按镜头合并，避免旧字段覆盖新姿态；未修改的原版记录保持原样。

## 卷轴显示、关联与相机编号

- 修复视角卷轴被通用相机辅助模型规则隐藏的问题。卷轴使用原生模型与材质，作为玩法物件显示，不依赖装饰开关；更新旧缩略图缓存。
- 卷轴属性提供额外视角、地图总览、第二地图总览下拉；存在组移到高级项。
- 关联已有额外视角直接使用；选择主镜头时复制构图并设为辅助用途，保留原主镜头，创建和关联合为一步撤销。
- 普通关联用稳定目标 ID 保持编辑关系，最终写回原生名称；改名、保存重开和旧历史不再使卷轴指向错误镜头。
- 新建额外视角从所选玩法镜头复制构图，或从主镜头开始；必要依赖独立复制，不破坏原对象。
- 修复已删除相机的历史编号被玩法物件复用，导致再次新建或构建冲突。新建、复制及组合批量放置避开历史编号与整段编号范围。
- 对确定已删除的冲突相机历史，仅在内存回放中重映射其编号与内部引用；原工程及现有物件保持原样，存活编号冲突不自动覆盖。

## 中键取样

- 只有严格静止的短促中键单击取样。原始位移、屏幕坐标、合并轨迹及松手事件携带的位移均参与判定。
- 快速下拖、移回原点、长按、导航、失焦与取消不取样；重复按下事件不能重置本次按压，拖动不会恢复成单击。
