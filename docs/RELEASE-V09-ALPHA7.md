# v0.9.0-alpha.7：选中即移动与完整镜头姿态

本阶段未单独公开，改动随 v0.9.0-alpha.8 一起发布。以下保留该阶段的布局移动、分屏取景入口、六轴调整与检查记录。

## 布局分屏

- 选中分屏后，整套布局中心显示 X/Y 移动柄；不依赖 W、普通选择／移动／旋转工具。拖动、切屏和撤销后保留移动柄。
- 工具栏移除“编辑整套镜头”按钮。保留所选分屏卡片上的“编辑镜头”，直接进入该屏取景。
- 整体移动只改变分屏网格起点，保留屏数、每屏尺寸、地形、物件及循环范围。一次拖动一步撤销；取消、失焦和视口外释放不提交。

## 分屏入口及坐标

- 入口直接传递镜头 ID 和所选屏坐标，不再只靠读取本机偏好推断。负坐标分屏、非零网格起点及空屏使用相同规则。
- 主画布立即采用该屏的镜头位置、观察点、视角及上方向。标题显示屏坐标；右侧坐标也显示当前屏，避免实际在看负坐标屏、参数却显示零屏。
- 退出恢复原自由视角。选择、查看及切屏不产生工程修改；同套分屏共用姿态，其他屏按网格平移。

## 六轴编辑与数据

- 普通、分屏及总览镜头不再按类型禁用 XYZ 平移／旋转。移除编辑器的 5°～89° 俯角钳制，方向立方体支持水平、下方和完整 26 个对齐方向。
- 使用完整位置、观察点和上方向保存姿态，保留侧倾；拖动、滚轮、对齐、属性调整和框住范围使用同一份姿态，不再重新压成高度与水平角。
- 中键移动取景、右键绕观察点旋转、滚轮调整距离；G/R 加 XYZ 设置世界轴约束。分区 X/Y 用于切换正在查看的屏。
- 工程格式版本不变，新增可选镜头 `pose`。旧工程缺省沿用旧数据；未编辑的原版镜头记录保持原样。完整姿态与旧位置／目标／水平角覆盖互斥，排队提交按镜头合并，避免旧字段覆盖新姿态。
- 数字属性修改同一份完整姿态；改变位置、FOV 或保存重开不清除侧倾。原生写回使用相机的 +X 前向、+Z 上向约定，而不是渲染器相机的轴约定。

## 原游戏运行范围

六轴可编辑和可保存，不等于原游戏的所有镜头路径都会采用完整姿态。

- 原生规则分屏会按房间中心、距离等参数重新计算相机。可以表达的姿态同步写回原生距离及偏移。
- 自由横向偏移、侧倾或其他不可由当前原生规则表达的姿态仍保存在工程及相机原生位置／旋转字段中，并在画布与构建检查中显示运行差异提示。
- 本次没有修改游戏程序，也不自动改成单场景、解除原生引用或重造触发区域。原生分屏任意旋转、总览及动态相机的最终运行效果仍需实机确认。

## 检查与用户验收

- 类型检查、生产构建及通用／原生数据回归分别记录。原生数据测试验证字段、引用、重开与编译，不代表已在游戏中运行。
- 新增界面自动检查覆盖负坐标分屏入口、实际画布姿态、右侧当前屏坐标、六轴操作、水平／下方对齐、不按 W 移动布局、取消及一步撤销。
- 回归有限布局、空屏导航、自动布局移动、返回大地图及装饰菜单。窗口检查覆盖 1366×768、1920×1080 和 125% 缩放。
- 建议先选中一屏进入取景，检查镜头和属性对应；退出后在布局中直接拖柄、撤销，再切换一屏。最后在隔离试玩中对照游戏实际镜头。
- 本次不启动或部署游戏，不关闭用户窗口，不操作正式存档。安装版、完整 ZIP 和 SHA-256 清单在本地生成并审计；人工安装与游戏内机制单列实测。
