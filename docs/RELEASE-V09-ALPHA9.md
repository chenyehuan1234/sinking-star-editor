# v0.9.0-alpha.9 · 试玩副本更新、复制进度与性能诊断

本版提供 Windows x64 安装程序、免安装 ZIP 和 SHA-256 校验文件。编辑器从用户自己的 Steam 安装读取原生资源。游戏和个人项目均不包含在分发包中。

## 更新后的副本处理

- 游戏更新后重新准备试玩，先在工作区临时目录复制和校验新版，再替换当前 `playtest-game`。
- 旧副本只在替换事务中作为临时回退保留。新版登记写入成功后自动清理，不再长期归档整套旧游戏。
- 同一游戏版本继续复用已有副本，不重复复制。原始关卡包备份、工程、测试存档及独立设置保留。
- 复制失败或游戏在准备过程中启动时保留旧副本，清理未提交的临时复制。
- 为复制中的临时目录写入归属标记。复制中途退出后，再次准备只清理所属进程已结束的半成品；活跃进程、未登记目录、工程和进度文件保留。
- 使用持久化替换记录处理更新中断：目录切换未完成时恢复旧副本，新版已到位但登记未写完时完成登记，然后清理回退目录。清理中断可以继续恢复。
- 路径限制在工作区内，拒绝链接及归属不明的副本；自动清理遇到工程或存档时停止。以前版本留下、没有本次事务归属的历史副本不会批量删除。

**更新期间仍需一份新版副本的临时空间**，不是增量补丁或资源共享。目标是更新成功后只保留一份完整试玩游戏，避免每次更新多留十几 GB。

## 复制进度

- 编辑器首次启动只检测和读取游戏，不自动复制整套游戏；复制发生在首次试玩或需要更新副本时。
- 工作台底部显示复制进度，存档试玩弹窗内也同步显示，临时试玩不增加确认弹窗。
- 按真实复制字节显示百分比、已复制／总大小、文件数量及当前文件；大文件通过流式复制更新，通知节流，避免每个小文件都刷新界面。
- 统计、校验、替换和清理阶段显示阶段提示，不使用虚构的百分比。复制达到 100% 后仍需完成校验与替换，再继续构建、启动。
- 成功、失败及后续普通阶段消息会清除复制条，避免残留忙碌状态。

## 性能诊断与试玩空间

- 「操作设置 → 性能诊断」可记录最多 30 秒的选择、拖动、放置、预览和资源读取耗时。采样在本机运行，可手动导出 JSON。
- 完整世界的分区差量由后台生成，界面应用变更结果。小关物件拖动仍在松手后提交。
- 试玩继续使用完整副本。已盘点实际分配空间，并核对模型、贴图候选与关卡部署写入路径；尚未验证原生只读共享入口。[测量、空间盘点与复现方法](PERFORMANCE.md)

## 验证范围

文件操作测试全部使用独立临时夹和不可执行的合成游戏数据，覆盖成功替换、程序单独更新、复制／登记失败、目录切换中断、清理中断、外部改动、链接、磁盘空间及原安装只读。

界面检查经真实预加载 IPC 通知验证工作台与试玩弹窗，覆盖百分比、阶段、结束清理、窗口尺寸及缩放。界面样例中的文件大小是测试数据，未再次复制本机完整游戏，也未启动或部署游戏、操作正式存档。

类型检查与开发构建通过，383/383 项通用与原生数据回归通过，其中副本与复制专项 28 项。复制进度界面检查 16/16 项通过，覆盖 1366×768、1920×1080 与 150% 缩放。持续进度通知未增加后台原生预览请求。性能基准使用独立工作台的鼠标输入，结果详见性能记录。
