# 使用与人工验收

当前本地版本为 **v0.9.0-alpha.6**。完整世界、小关和入口的操作步骤见 [本版验收](V09-ACCEPTANCE.md)，功能及自动检查范围见 [发布说明](RELEASE-V09-ALPHA6.md)。历史版本文档不是当前行为说明。

## 首次启动

1. Windows x64 安装版按向导安装；ZIP 必须完整解压，不能只移动 exe。核对 SHA256SUMS.txt。程序未签名，不需要 Node.js。
2. 需要 Steam 原游戏。启动自动发现安装；手动选择时选包含 sinking_star.exe 的文件夹。没有游戏时可阅读 F1 离线指南。
3. 工作区在首次设置和工程菜单查看；更换磁盘重启生效，旧工程不自动搬迁。安装和免安装共用本机偏好，卸载默认保留工程。
4. 全新用户、多个 Steam 库、失效旧路径、中文路径、取消选择和错误目录仍建议人工复查。

## 编辑一个小关

新建空白关，放置出口、石块、开关和门闸，设置频道与方向，保存后重新打开。中键单击取样，拖动只导航；地面与墙体左拖矩形添加、右拖矩形擦除，空白处右拖旋转。取消不应产生修改，提交后一步撤销。F1／Ctrl+F 查操作，Ctrl+Shift+P 搜索命令；键位以操作设置和指南当前显示为准。

## 试玩与正式存档

[隔离机制与检查范围](PLAYTEST-ISOLATION.md) 保留。使用编辑器顶栏受管入口；临时试玩直接启动，不增加永久测试档，存档试玩明确选档。当前已验证程序的独立存档路径只显示测试档战役；未经验证的程序仍阻止启动。不要手动运行旧共享副本。

编辑器不会退出正在运行的游戏。游戏内机制、完整世界循环、跨层和进度结果由用户在隔离测试档中检查；本版自动回归、离屏截图和运行包重读不等于实际通关或安装升级测试。

## alpha.2 显示与取样

短促中键单击取样；拖动、长按、往返、滚轮及越界取消均不取样。装饰首次默认关闭，切换地形显示不得自动打开装饰，关闭装饰仍有地形参考。主动打开布景后，云、原生编辑标记和阴影辅助仍默认隐藏；缩远大地图应保留原始模型及整数地形格，不再变为粗缩略图。

新增检查：关卡搜索默认只有图标；物件按实际名称／模型区分，单击高亮、双击聚焦，画布选中后列表滚动。锁定的可见物件仍可查看轮廓，不能修改。检查碰撞地形锁与原版布景锁，水域在装饰关闭时仍可拖动；移动操纵柄连续操作后保持绑定。布局菜单与立方体、镜头三轴重叠时，菜单应完全位于上层并接受点击。

## 本地 alpha.3 镜头与分屏

见 RELEASE-V09-ALPHA3.md。先检查中键方向与 G/R＋XYZ，随后验证实际地面取点、三轴微调、取消和一步撤销，再检查网格起点／每屏宽高和整套取景。自动检查不代表实机通关或镜头区域切换已验证。

## alpha.4

检查自由画布默认分屏线、自动铺满和手动横纵屏数保存重开；镜头只有一个面板，原生区域在高级管理。画一屏大小、画循环边界分别确认／撤销，验证取消、失焦、视口外释放及正交俯视结束恢复。循环只改 XY；规划数量不应触发原生预览或改变游戏构建。

## alpha.5 分屏与多镜头

单击一屏地面后点击“编辑镜头”，确认从选中屏开始；双击直接进入，物件选择及空白拖动框选保持有效。退出恢复自由视角，只查看不能产生撤销步骤。分别在 16:9 与 4:3 检查构图，保存重开后再从隔离试玩核对。导航里的“自由定位”不能作为游戏构图验收。

多镜头及视角卷轴的设置和限制见 [镜头切换说明](CAMERA-SWITCHING.md)。原生三层选择、卷轴解锁后的切换及区域过渡需另做实机对照；本轮没有运行游戏。

## alpha.6 分屏导航完整性

等待每屏格数提交完成后，将布局设为 3 列 × 2 行。自由定位列表应有 6 屏，未铺地形的屏也能定位；切换每屏尺寸、起点、当前高度或规划数量后，条目及落点同步。超过 500 屏时使用前后翻页，编号连续、最后一屏可达。浏览不改工程，不触发原生预览。

普通、分屏及总览镜头均检查 XYZ 平移和旋转、水平／下方对齐及侧倾保存。分屏卡片进入后核对主画布的实际位置、观察点与屏坐标；原生规则分屏不能表达的自由姿态有明确提示，不将编辑器预览当作游戏实测结果。布局选中后无需 W 即显示整套移动柄，移动及撤销后仍显示。

本版更新：默认分屏移动开放 Y/Z，分别写入南向距离／高度；布局模式只显示已设置的横纵屏数，拖动中央 X/Y 柄或输入位移可整体移动。检查自动布局移动时屏数不跳变，一步撤销同时恢复规划与起点。

默认不选择水域也应看到全部可见流向。开启原版装饰不应再出现实心云球或星云竖板；特殊效果与辅助可单独查看轮廓。验证返回大地图恢复位置、装饰菜单外点及 Esc 收起。

## 数字输入自动生效

选中角色，保持位置 X 输入框焦点，输入 10 再输入 11，确认画布立即预览并自动提交；一次撤销回到输入前。频道保持焦点输入与点击增减均自动生效；64 位值必须精确。空白、单独负号或未完成指数不能写成零。镜头高度也应无需 Enter 即生效，连续修改合并撤销。检查输入法、取消、保存重开，以及相邻字段操作不会被误合并。


## alpha.8 卷轴与镜头列表

1. 关闭装饰显示，新放置视角卷轴。画布应显示卷轴原生模型，可直接选择、移动与取样。
2. 卷轴属性的“额外视角”下拉选择辅助镜头。选择正常游玩镜头时应复制为辅助视角，原主镜头保持不变；一次撤销同时恢复创建与关联。
3. 地图总览与第二地图总览分别设置、清除，不能覆盖普通辅助视角。所属存在组位于高级，与镜头关联无关。
4. 镜头列表应直接显示正常游玩、辅助视角、地图总览三个分组，不再有“包含总览／辅助镜头”筛选；高级管理用“镜头用途”区分主镜头与卷轴视角。
5. 改名、保存重开后确认卷轴仍关联同一辅助镜头。实机获取卷轴及切换视角单独验证，本轮自动检查没有运行游戏。


## alpha.8 镜头单页验收

- 第一次打开，只有本关画面规则、镜头清单展开。三类相机位于一张清单并标明用途，不再有重复下拉、重复属性页编辑器或五块原生分类。
- 图中数字位于精确参数，默认折叠；展开、选择、阅读和失焦不修改原始精度。名称、用途及锚点引用位于关联与原生设置。
- 搜索图标检索名称、用途与 ID；收起恢复完整清单，重新打开保留搜索词。新增额外视角从当前玩法镜头复制，原镜头保持不变，一次撤销移除新镜头及用途配置。
- 区域与相机交替选择，不能同时显示不同对象的参数。从普通属性、卷轴、分屏黄框进入，核对画布标题、当前条目及实际取景对象一致。
- 分屏参数只管理网格；布局显示既定横纵屏数，中央移动柄无需 W。普通取景入口不继承旧分屏上下文。
- 保存后重新启动工作台，核对本关折叠、搜索、选中与面板滚动恢复；切到另一关不会带入对象选择。
- 在 1366×768、1920×1080、125%／150% 缩放检查按钮、列表、折叠与滚动。图像及原生记录检查不代表游戏内切换已经验证。

## 镜头清单与导航取景补充（alpha.8）

1. 开启规则分屏，设置每屏 8×9、2 列×1 行：摘要应横向显示两项统计，布局按钮独占下一行，窄面板不应逐字换行。
2. 镜头清单单击只选择；双击普通、额外视角和总览，均应进入该镜头取景。结束按钮应为“完成镜头编辑”，完成或 Q 返回原自由视角。
3. 上方图标栏应有分屏边界图标，首次升级默认开启，简洁模式可见；手动关闭再开启，黄线同步。
4. 导航下拉查看某镜头，再双击同一镜头：位置、观察点、朝向、侧倾、视角和构图比例应一致。分屏构图导航与编辑相同行列也应一致。查看、切换和完成均不应新增撤销记录。
5. 在 1366×768、1920×1080 及 125%／150% 缩放下检查摘要和按钮；此为编辑器构图验证，游戏内动态切换仍另行验收。
