# v0.7.6-beta.1 用户验收

本页是待操作的检查步骤，不表示已完成手动验收。无需关闭原游戏来检查编辑器连接，试玩部署需要由你先退出游戏。

## 首次启动与安装

1. 安装版使用当前 Windows 用户安装，检查桌面与开始菜单入口；免安装版完整解压后运行。无需 Node.js。
2. 用全新 Windows 用户或独立配置目录启动，检查 Steam 默认库、其他磁盘库自动发现。多个安装时应能选择。
3. 手动选择 Steam 总目录或缺文件的文件夹，检查具体错误和重新选择入口；取消选择不应清空已有设置。
4. 选择包含 sinking_star.exe 的目录，连接成功后重开，应记住位置。旧目录失效后应重新检测，不停在空白场景。
5. 未连接游戏时打开 F1／Ctrl+F 指南，关闭后返回首次设置页。
6. 修改工作区，确认新路径、重启生效提示以及旧工程仍在原位置；卸载不得删除工程。

## 编辑与保存

1. 新建空白关，放置出口、石块、开关和门闸，修改频道，保存并重新打开。
2. 载入三个内置示例入口，检查内容、模型、依赖与来源版本。
3. 检查正负坐标、XY／XZ／YZ 地形矩形、擦除、多选、拖放虚像与一步撤销。
4. 开旧版本工程，应说明来源不匹配并保留原文件，不自动更改其版本或哈希。
5. 在 1366×768、1920×1080 及 Windows 125%／150% 缩放下检查首次设置、目录列表、指南与工作区说明。

## 原游戏试玩（仅由用户操作）

1. 退出正在运行的原游戏或测试游戏，再发起当前关、临时组及整工程试玩。正在运行时应被拦截，编辑器不会替你关闭游戏。
2. 首次准备应显示预计复制大小；不足空间时停止并提示更换工作区。使用专用测试战役，确认原安装未被替换。
3. 依次检查“加载成功”“机关可操作”“可以通关”，分别记录，不把加载等同于通关。
4. 对 green_metamirror、skipping_near_beams_v2、annoying_orange_v3 以及自建区域分别检查跨屏、高度归属和镜头切换。
5. 结束测试后按既有恢复流程恢复普通战役选择，确认个人存档保留。
