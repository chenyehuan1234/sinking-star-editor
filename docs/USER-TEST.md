# v0.7.10-beta.1 用户验收

本页是待操作的检查步骤，不表示已完成手动验收。无需关闭原游戏来检查编辑器连接，试玩部署需要由你先退出游戏。

## 首次启动与安装

1. 安装版使用当前 Windows 用户安装，检查桌面与开始菜单入口；免安装版完整解压后运行。无需 Node.js。
2. 用全新 Windows 用户或独立配置目录启动，检查 Steam 默认库、其他磁盘库自动发现。多个安装时应能选择。
3. 手动选择 Steam 总目录或缺文件的文件夹，检查具体错误和重新选择入口；取消选择不应清空已有设置。
4. 选择包含 sinking_star.exe 的目录，连接成功后重开，应记住位置。旧目录失效后应重新检测，不停在空白场景。
5. 未连接游戏时打开 F1／Ctrl+F 指南，关闭后返回首次设置页。
6. 修改工作区，确认新路径、重启生效提示以及旧工程仍在原位置；卸载不得删除工程。

## 编辑与保存

1. 新建空白关，放置出口、石块、开关和门闸，修改频道，保存并重新打开。
2. 载入三个内置示例入口，检查内容、模型、依赖与来源版本。
3. 检查正负坐标、XY／XZ／YZ 地形矩形、擦除、多选、拖放虚像与一步撤销。
4. 开旧版本工程，应说明来源不匹配并保留原文件，不自动更改其版本或哈希。
5. 在 1366×768、1920×1080 及 Windows 125%／150% 缩放下检查首次设置、目录列表、指南与工作区说明。

## 原游戏试玩（仅由用户操作）

1. 退出正在运行的原游戏或测试游戏，再发起当前关、临时组及整工程试玩。正在运行时应被拦截，编辑器不会替你关闭游戏。
2. 首次准备应显示预计复制大小；不足空间时停止并提示更换工作区。使用专用测试战役，确认原安装未被替换。
3. 依次检查“加载成功”“机关可操作”“可以通关”，分别记录，不把加载等同于通关。
4. 对 green_metamirror、skipping_near_beams_v2、annoying_orange_v3 以及自建区域分别检查跨屏、高度归属和镜头切换。
5. 结束测试后按既有恢复流程恢复普通战役选择，确认个人存档保留。


## 循环关与角色同步（本轮待实机确认）

1. 新建空白关，取消选择，设置自定义边界：起点 `[0,0,-2]`、格数 `[16,16,8]`，开启 X/Y 循环，添加出口。保存重开，确认画布范围和参数保留。边界框是编辑辅助，不是重复场景。
2. 在原生测试游戏中分别跨越东、西、南、北边界及角落，记录“加载”与“循环行动”结果。另用原版 `boot_cycle_warrior` 对照；检查 Z 层、能力和分屏时不要把画面覆盖等同于逻辑边界。
3. 放两名同外观牧师，先检查独立切换。多选后“所选同步为一组”，再在游戏里选组移动；检查同时行动、遇阻、推物和切换行为。
4. 将其中一名换成另一外观，确认保存后控制关系不变；不同外观是否联动取决于明确的控制关联。分别做“各自独立”和“复制为同步角色”。
5. 独立复制整组、只复制组中的两名、删除原锚角色、撤销、保存重开，检查组内关系。使用 `clone_maze` 对照同步，用 `end1` 对照同外观独立。
6. 在专用关验证衣柜、变形石块、存在状态和角色失效情形；这些原生行为不能只凭编辑器中的组标识显示判定通过。


## 玩法放置优化（v0.7.8）

1. 小关中在顶面和侧面分别用矩形、笔刷添加／擦除；核对预览与落点、负坐标和手动工作面。
2. 用面拉伸点击连续裸露面，上拖添加、下拖削减，验证一步撤销；分别用 Esc、右键、失焦和视口外松手取消，确认周围机关未被删除。
3. 选多个玩法物件，用方向键和 Shift+PageUp/PageDown 微移，验证世界轴方向、连续快按、锁定对象和输入框焦点。每次按键提交一次，不按住连发。
4. 选中普通开关或门闸，按 L 后点选另一普通机关。确认加入目标频道、目标频道原成员参与联动，撤销可恢复；怪物门和特殊开关应拒绝，右键取消不删除物件。
5. 修改新命令键位并重开；旧自定义键占用方向键或 L 时保留旧键，提示新命令需要另设。


## v0.7.9 操作效率与可靠性（待用户操作）

1. 在原版多高度关与自己的大关中反复选择、拖动、连续放置、改参数；观察松手后是否闪回。打开命令搜索、指南，或切关、失焦、视口外松手时，未完成动作应取消；保存等待已提交的修改处理结束。
2. 将重叠机关点选候选列表逐一选中；隐藏其中一件、锁定另一件。列表仍能查看锁定项，但参数、R、Delete、分组复制、批量换图卡不得修改锁定成员。
3. 创建分组、加入／移出成员、改名、复制、删除成员、撤销并保存重开；解散不删除成员。大地图新增物件及入口也可分组，原版背景与基础地形不参与。
4. 只显示选中时检查地形支撑仍在；临时显示关联物件后恢复原过滤。比较选中相关／当前频道／全部关系，检查频道色标、方向引用、失效目标定位及 L 点选预览。特殊开关和怪物门不显示普通控制线。
5. 地形面拉伸先框选局部，再沿箭头增加／削减或输入正负层数；分别覆盖 XY、XZ、YZ、负坐标、孔洞、上下层、Esc、失焦、视口外松手。确认 4,096 格和 128 层上限；超限不提交。
6. 方向键按住后重复微移，混合方向、相反方向和 Shift+PageUp/PageDown；全部释放只需撤销一次。输入框、放置和镜头编辑中不得移动物件。
7. 多选同类角色后更换图卡，检查能力字段、名称、引用与控制身份；复制整组开关和门为 X/Y/Z 阵列，确认每个副本内部相联、各副本独立。共享模式明确与原机关联动。超出 2,000 个新物件时不能确认。
8. Ctrl+Shift+P 搜索中文名称、别名与改过的快捷键；检查不可用原因、Enter、Esc、焦点恢复和输入法。Ctrl+F 仍检索指南；旧自定义键不应被重置。
9. 用原生单关和专用临时组分别验证加载、机制操作及通关；不将自动数据检查或屏幕截图视为实机完成。完整循环大地图继续不在本版验收范围。


## 中键取样与放置修正（v0.7.9-beta.2）

1. 在空白小关放置石块、开关和门闸。中键单击已有物件，确认立即进入同配置虚像并可连续放置；右键结束。中键拖动只导航，松手不取样；游戏镜头编辑中仍固定为平移。
2. 中键单击地形切回地形绘制；点“机关”恢复刚才的物件，点“地形”恢复上次地形工具。反复切换不应留下旧虚像或等待整关重载。
3. 俯视和较陡俯视分别在地形顶部、边缘、侧边起笔，自动工作面应水平展开。换成侧视再确认竖直面；手动 XY/XZ/YZ 应保持指定平面，拖动中不跳面。
4. 对比角色、开关、门闸与透明／裁切材质的虚像和放置后的模型。调整虚像透明度 15%～80%，核对贴图、配饰显隐、轮廓和矩形预览，不应出现整片消失、旧模型残留或双层加深。
5. 刚取样立即切地形、切关、撤销或取消，旧的异步结果不能恢复旧物件。矩形在视口外松手、Esc、失焦时不提交，整片预览只产生一步撤销。
6. 在操作设置关闭中键单击取样，确认仍可中键导航及使用 I 吸管；旧鼠标设置、旧工程和保存重开正常。


## 浏览位置与上次小关（v0.7.9-beta.3）

1. 打开原版目录，展开几个区域并滚动到中间。关闭后重开，核对展开和位置；搜索一个关卡，添加后再次打开，核对搜索、位置及上次添加项标记。辅助场景开关和重启后的目录状态也应保留。
2. 在角色分类搜索并展开变体，滚动到中间；切方块分类使用另一个搜索和位置。来回切换时分别恢复各自状态；收藏、最近使用也各自保留。
3. 隐藏再显示素材栏、重启编辑器，核对分类与位置。调整缩略图大小、窗口宽度和页面缩放，原来浏览的物件应尽量仍在可见区域；资源减少时不出现空白长列表。
4. 保存工程，选择某一小关后重开，应直接进入该小关并恢复已有编辑视角。删除该关后打开不含它的旧副本，应安全回到大地图。切换另一工程时使用该工程自己的记录。
5. 单独改变搜索、展开和滚动不应使工程变为未保存，不增加撤销记录，不触发原生预览。未安装游戏时仍可阅读指南。


## 快捷槽、精确地形与取景（v0.7.10）

1. 新建小关，修改门闸名称、方向与参数后保存到槽 3；再修改原件，检查槽内快照不变。连续放置两份，检查独立 ID、频道及完整外观能力，分别撤销和重做。
2. 拖入图卡到槽 4，检查只绑定不误放置；右键改名、更新和清空。快速 R 后切槽再回来，方向应保留。输入框输入数字、中文组字和键位录制不应触发槽位。
3. 同一槽在两个关分别设置不同锁定高度，切关、保存重开、重启后检查分别恢复。原游戏更新后旧来源槽不能直接使用；损坏和失败写入应说明原因并保留备份。
4. 分别在 XY、XZ、YZ 的正负坐标放置固定矩形，检查长宽厚、反向展开和完整虚像；拖动矩形也可改厚度。擦除只作用于实际地形，不删除机关；每笔撤销一次。超出 4096 格、128 层、Esc、失焦和视口外释放不提交。
5. 大地图检查 XY、一层限制及超出地图边界的提示；物件槽不能在大地图启用。原来的中键取样和右键导航／删除规则应保持。
6. 自由编辑调整位置和角度，采用当前视角后检查游戏镜头位置、目标和 FOV。保存重开、撤销后仍正确；分屏、总览、翻转和动态引用显示不可用原因，不应破坏原模板。
7. 在四种构图比例下框住关卡和选中，检查留边不接受中键、右键和滚轮，退出恢复原自由视角。新空白关扩建后仅提示；忽略不修改镜头。
8. 在 1366×768、1920×1080、Windows 缩放下检查快捷栏、尺寸面板、镜头条和焦点。游戏内加载、机关操作、通关和实际构图由用户在专用战役中分别验收。
