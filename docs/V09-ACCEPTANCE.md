# v0.10 验收步骤

本页是待人工操作的步骤，自动结果见发布说明。不要使用正式存档做测试；编辑器不会替你退出正在运行的游戏。

## 多工程、关卡机制和地形配色

1. 用顶部 ＋ 新建工程，保留修改，拖出标签并在独立窗口撤销。拖回另一个窗口的标签栏，保存后重开，检查工程与选中的关卡。
2. 在关卡属性展开「玩法时序」，分别设置下落、荷叶、飞石和小车。保存重开后检查各项数值，恢复其中一项时应采用该模板的有效值。
3. 导入「光束发射器之库」西 1，检查每屏 6×6。在自制分屏关启用「房间通电高亮」，在布局里选中一屏并预览。将宝石槽与两台发射器划入不同房间，临时试玩观察供电和蓝边。
4. 选择三棱镜，在属性里分别用带青色和带紫色的两套配置试玩。按游戏的互动键轮转，检查取消的颜色是否跳过。
5. 选择地面或墙体工具，打开「地形配色」。设置两个默认色，在顶面和侧面分别刷色，拖动一笔后撤销一次。保存重开、旋转粘贴和临时试玩时对照颜色与落点。

## alpha.9 副本与诊断

1. 在有足够空间的独立工作区连接 Steam 原版。首次打开编辑器只连接游戏；首次准备试玩时，状态栏或存档试玩窗口应显示字节、百分比与文件数，复制后应进入校验阶段。
2. 存在旧副本且 Steam 游戏已更新时，再次准备试玩。校验及替换成功后应只保留一份当前副本，工程、隔离测试档和独立游戏设置应仍可用。复制失败应保留旧副本；跳过任何会使用正式战役的验证。
3. 打开「操作设置 → 性能诊断」，分别在小关、密集大地图和地形框选中复现操作。底栏停止后检查样本、P95 和最慢耗时，导出 JSON 后确认不含工程名、路径或物件 ID。[自动测量与方法](PERFORMANCE.md)

## 区域复制与三维自制世界



1. 在原版世界画布开启「区域复制」，拖出跨区矩形并设置最低、最高 Z。按 Ctrl+C 后切换工程，按 Ctrl+V 查看轮廓与虚像。也可以重启后从最近的区域剪贴板粘贴。
2. 旋转并放到自制大地图边缘，选中扩图确认。检查重叠地形、负坐标、高低差、水流方向和框外解锁条件。多个入口共用一个源小关时，应指向同一个导入副本。
3. 设置 Z 显示范围，然后分别放置或取样上下层地形。通过入口属性调整实际 Z，检查旧二维工程首次保存时提示另存。
4. 撤销一次应恢复原边界、地形、入口和关卡。重做并保存重开，再导出或使用隔离试玩检查高低层碰撞和入口进入目标。

## 世界、目录与保存

1. 工程菜单选择“导入／编辑原版三层世界”。确认仍是原工作台，左侧有“大世界”和分组目录，素材、属性、快捷槽及停靠布局保持一致。
2. 检查 993 个小关与辅助场景、920 个入口。入口不是小关的完整计数，未挂入口场景也保留。
3. 搜索区域或小关，新建分组、改名、拖动排序和跨组移动关卡。保存、重新打开，检查分组与关卡次序。解散分组不删关卡。
4. 切换地下、地表、天空，输入包含负数的任意 Z 范围，检查放置高度不被改变。平移、缩放跨区域浏览，概览放大后进入细节。
5. 打开旧 v4，保存时选新的 v5 文件名；确认旧文件仍在。普通 v3 继续编辑，不自动变为原版世界。
6. 切换小关后检查原生材质显示无需重按；各关编辑视角、目录展开和滚动位置应恢复。

## 新关、入口与编辑

1. 新建空白关，放出口、开关和门闸。复制后只改副本，原关不变，也没有自动新增入口。
2. 返回“大世界”，放置入口前选目标，在不同 XYZ 高度各放一处。修改名称、目标和位置，双击进入对应小关。
3. 删除自定义关，确认关联入口数；一步撤销后，关卡、入口及编辑分组均恢复。
4. 删除仍被原生序列或其他对象引用的场景，应显示具体依赖并阻止删除。可以先单独删除地图入口，不能强制丢弃未知依赖。
5. 解锁支持编辑的原版物件，测试取样、移动、复制、地形矩形、水流和相机。未支持的原生类型应只读并保留数据。
6. 中键按下不取样；保持位置松手进入放置。移动后松手只平移，即使移回原点也不取样。镜头编辑中中键只平移。
7. 对旧错色门闸使用“恢复素材颜色”；核对门体颜色与底座分开处理，频道、方向、响应、位置和身份不变。保存、重开检查。

## 导出与隔离试玩

1. 单关、关卡组和全世界分别导出工程到中文目录；重新打开。再导出运行包，核对 manifest 校验值。取消路径选择不写文件。
2. 有出口依赖未选小关时，应提示把依赖一起选入；完整世界构建不重新生成二维地图。
3. 使用已验证隔离路径的游戏版本，按当前关／组／全世界分别临时试玩。临时试玩不弹选档窗口，状态栏显示检查、构建、准备和启动。
4. 存档试玩明确选择测试档，检查退出、重开和独立设置记忆。原游戏运行时不能部署，不能自动关闭原游戏。
5. 在隔离档里对照门体实际颜色、中键手感，以及世界四边／角落循环、跨层连接、入口解锁和进度。以上游戏内验证尚未在本轮执行。

## 显示与性能

在 1366×768、1920×1080 及 Windows 缩放下检查目录、属性、Z 范围、指南和弹窗。连续跨区域导航、切关、取消加载，旧结果不能覆盖新视野；未完成手势取消不产生撤销记录。记录首次加载与缓存后的延迟、整个进程的内存，并与文档中的离屏／数据进程范围区分。

范围外有效对象引用应标为“范围外”，点击可定位，不能显示为缺失。世界频道列表仅计当前加载成员；全世界频道批量合并暂不开放，点选目标加入其频道仍可使用。
