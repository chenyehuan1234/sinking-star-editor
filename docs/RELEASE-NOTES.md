# v0.7.8-beta.1

玩法放置优化；本版不包含完整 v0.8 世界编辑与解锁进度改造。

- 统一地形笔刷和矩形的贴面坐标、竖直工作面与半透明预览；一笔松手只提交一步。
- 新增连续裸露面的拉伸／削减，预览实际影响格，支持取消、负坐标和上限检查。旧版大地图基础地形暂不支持面拉伸。

- 新增普通开关／门闸的点选频道关联（L），拒绝怪物门和特殊开关；目标点击不启动物件拖动，右键可取消。
- 新命令纳入改键设置，保留占用新增默认键的旧自定义键位；更新离线指南。

类型检查通过；当前 Steam Build 26249670 的 141 项自动测试全部通过。无游戏的干净源码检查中，74 项通过、67 项原生测试明确跳过，并完成构建。界面手势及游戏内行为仍需用户操作验收；未启动游戏或切换存档。

# v0.7.7-beta.1

原生循环边界与角色同步控制，兼容版本 3 工程。

- 关卡设置新增“循环与逻辑边界”：沿用模板或固定整数边界，使用原生 X/Y 循环，Z 不循环。自定义边界不随物件移动扩张；保留原版遮罩。
- 角色属性新增“原生角色控制”：独立、加入现有控制组、多选同步、同步副本及组成员定位。
- 控制以原生 `Guy.turn_order_id` 为依据；同外观可以独立。更换外观与能力预设保留控制身份。
- 独立复制、区域粘贴及部分组成员复制保留副本内部关联；主动拆组同步处理变形石块中的控制身份。删除原锚角色不擅自改组。
- 更新离线指南、搜索内容和用户验收步骤。

本轮检查：类型检查通过；当前 Steam Build 26249670 的 133 项自动测试全部通过，无跳过。六组公开示例重新生成、读取并构建；原版循环关和显式同步关未修改时实体数据逐字节保留。检查前后原包和游戏程序未变化。

干净源码在不连接原游戏的环境下完成类型检查、构建及通用测试（66 通过、67 项原生集成测试明确跳过）；未使用个人工作区。

本轮没有启动游戏或完成界面、安装卸载及游戏内验收。循环边界穿越、同时行动、遇阻、衣柜／变形和存在状态等需用户在专用测试战役中确认。下载需要已安装原游戏；可执行文件未签名。
