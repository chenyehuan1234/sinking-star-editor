# v0.11.0 · 工程首页与独立单关

提供 Windows x64 安装版、免安装 ZIP 和 SHA-256 校验文件。运行编辑器需要本机的 Steam 版《沉星之序》。程序未签名。

## 新增与调整

- 启动进入「我的工程」。展开工程可查看分组及关卡，检索可匹配工程名、分组名和关卡名。工程与关卡缩略图可点击放大。
- 顶栏「＋」可新建工程或新建单关。单关直接打开 16×16 空白场景，沿用素材、属性、镜头、机关和撤销工具。单关独立保存为 `.sstar.json`，可再次打开、加入关卡库或导入其他工程。
- 从工程展开列表跨组勾选小关，加入本机关卡库。关卡库区分「我的关卡」和「已下载」，支持直接试玩、编辑副本和另存分享包。首页可重命名工程和库条目，删除会先确认，再将本地文件移到回收站。
- 主页左下角增加「报告问题」「功能建议」，打开 GitHub 对应反馈表单。
- 桌面与独立网页提供社区工程和社区关卡库，支持搜索、发布、下架、完整下载和逐关下载。分享文件使用 gzip 压缩，必要的跨关依赖随包保存。社区服务目前支持本机部署与预览。

## 修复

- 补齐本机关卡库的实际场景缩略图。历史条目可自动补图，并缓存结果。社区单关可使用作者提供的小关预览作为封面。
- 桌面社区作品详情保留「我的工程」「关卡库」「关卡社区」三个返回入口。网页侧栏常驻社区工程与关卡库。
- 关卡库试玩启用固定的独立测试战役条目，每次清除该条目上次的关卡历史，避免读到不同设计的旧进度。编辑器试玩启动优先选用测试战役，正常游戏和测试游戏仍共用手动载入列表。原版战役使用 Steam 启动。

## 验证范围

- Steam Build `26787118` 通用及原生自动回归 410 项、社区检查 6 项通过。使用实际场景验证目录、缩略图、单关打开、独立保存重开、导入与试玩构建。
- 在临时存档目录验证启动优先级、关卡库旧进度清理及正式存档文件保持一致。游戏内实际启动与暂停菜单仍待手动验证。

# v0.10.3 · 大地图移动与试玩修复

提供 Windows x64 安装版、免安装 ZIP 和 SHA-256 校验文件。运行编辑器需要本机已安装的 Steam 版《沉星之序》。程序未签名。

## 新增与调整

- 顶栏「试玩」旁的下拉菜单新增 **「从头试玩整个工程」**。每次从地图出生点、未通关状态开始，清空该模式上一次的地图和关卡历史。主按钮继续试玩所选范围，并继续使用原有测试进度。两种方式都沿用游戏当前的画面和声音设置。
- **大地图入口属性统一**，入口和普通物件共用属性布局、变换、朝向和原版图卡窗口。目标关卡、分组和解锁条件仍可在入口属性里编辑。
- **小键盘 4／6／8／2 可逐格移动**，方向键也可沿地图 X/Y 轴移动选中项。升级时保留已有自定义键位。

## Bug 修复

- 修复 **大地图主角无法移动**，主角现在支持普通物件的移动操作。拖轴、键盘微移和属性坐标都写入地图出生点，修改可撤销。
- 修复 **大地图入口没有移动柄、按方向键无效**，入口支持普通的画布选择、W 移动柄与逐格微移。松手提交位置后保持选中，移动和微移各可一步撤销。
- 修复 **入口名称常驻和属性贴边**，画布只显示选中入口的名称。属性栏使用和其他物件一致的内边距。
- 修复 **冰封屏障初始状态写入错误**。独立屏障曾继承原版剧情分组标记，相关关卡通关后会播放解冻动画，初始阻挡却异常。现在清除这些标记，并写入冻结的初始状态及对应关卡的解锁引用。
- 修复 **按暂停菜单时游戏闪退**，将触发 DirectX 12 崩溃的河流菜单背景换为原版英雄区背景。
- 修复 **新版游戏被独立存档检查拦截，无法启动试玩**，试玩副本直接运行原版可执行文件，使用游戏的存档目录。载入菜单也会显示正式战役。正式战役请在 Steam 原版游戏里打开，避免测试地图进度写回正式战役。

## 验证范围

- Steam Build `26787118` 的通用及原生自动回归共 409 项通过。重新编译了一个自制大地图的两块屏障，核对冻结状态和入口引用。
- 在编辑器检查了入口的鼠标拖柄、小键盘移动和撤销，以及主角位置写入、从头试玩入口。属性栏检查了 1366×768、1920×1080 和 125% 缩放。
- 本机开发版游戏日志确认从头试玩加载了大地图、完成了一关，并成功打开暂停菜单。冰封屏障的实际碰撞仍待专项游戏测试。

# v0.10.1 · 大地图镜头与机关关联

Windows x64 安装版、免安装 ZIP 和 SHA-256 校验文件。需要自己安装 Steam 版《沉星之序》。编辑器从本机安装读取原生模型和关卡，发布包只包含编辑器及公开示例。程序未签名。

## 自制大地图

- 入口属性采用原生样式图卡，支持更换外观、调整位置／旋转／缩放／大小、画布取点和设置解锁条件。目标关卡分组、编辑分组和原生分组分别显示。
- 「编辑大地图镜头」直接用主画布取景。正常游玩、地图总览、额外视角和规则分屏共用镜头面板。整图构建会写入大地图镜头配置，独立小关保存各自的配置。

## 机关关联

- 引用可按名称、类型、ID、关卡分组和原版区域搜索，也可从画布点选。重叠目标会列出候选，右键或 Esc 取消时保留来源选择。原版完整世界支持搜索视野外物件。
- 新放置冰封屏障只生成屏障本体。最多可关联四个解冻条件，支持全部或任一满足。剧情判定器、原生标记及部分完成放在高级项。删除入口会提示引用失效，仍可保存草稿。
- 自制地图入口重排后，解冻条件仍指向原入口。跨工程复制区域时会重连框内入口，并提示处理框外依赖。
- 普通开关和门闸可在「机关关联 → 频道」中搜索、定位、建号、改号或合并。频道保留 64 位整数精度，合并前列出受影响物件，支持撤销。

## 分屏与地形

- 分屏取景可选择来源镜头。普通镜头、规则分屏及地图总览分别保存。分屏模式构建时使用所选分屏来源，保留原版多高度镜头。原游戏会按每屏中心重算取景，编辑器会提示可能无法在游戏中复现的偏移或旋转。
- 分屏显示下拉可锁定分屏。锁定后可直接选择地形和机关，布局及选屏工具仍可编辑分屏。黄色虚线按画布投影绘制，在侧视、正交和透视时保持宽度。
- 循环关的分屏导航覆盖完整周期。循环边界截断房间时会提示具体轴，可一键向外对齐整屏。宝石供电预览与分屏采用同一房间归属。
- 玩法时序界面按项目显示原生默认值与覆盖值，房间通电与亮边分开显示。地板和墙体素材卡可设置放置颜色，中键取样会带上命中的实际面颜色。

## 兼容性与验证

- 适配 Steam Build `26787118`，修复新版程序中的源码路径被误识别为对象类型，导致保存失败的问题。完整世界在此版本读取到 920 个入口和 998 个小关及辅助场景。
- 在 Windows 上检查了自制入口缩略图、样式切换、分组显示和大地图分屏保存。原生检查覆盖文件读取、保存重开、原生构建及对照回读。
- Build `26787118` 的独立存档隔离尚无实机验证，试玩启动继续受保护。自动测试和编辑器检查未启动游戏。

# v0.10.0 · 多工程与关卡机制

提供 Windows x64 安装版、免安装 ZIP 和 SHA-256 校验文件。需要已安装的 Steam 版《沉星之序》。编辑器从本机游戏安装读取素材和关卡。

## 多工程与区域复制

- 顶部工程标签支持新建、打开、排序、切换和拖出独立窗口。拖回其他窗口的标签栏可合并。每个工程保有各自的编辑状态、撤销历史和未保存标记。再次打开同一工程文件会定位到已有标签。
- 区域剪贴板可在工程和窗口之间使用。框选原版大世界时可复制多高度地形、水域、玩法物件、入口及关联小关。粘贴时可旋转，目标越界时可确认扩图。外部解锁依赖和重叠冲突会列出待处理项。
- 自制大地图支持三维地形、不同高度的入口和出生点，以及原生 Z 范围。旧二维工程打开后可另存为三维工程。

## 新增关卡设置

- 关卡属性增加「玩法时序」。下落速率使用倍率，荷叶、飞石和小车使用移动间隔，荷叶起动延迟位于高级设置。每项可恢复模板。
- 「布局分屏」支持预览房间通电高亮，并标出该层的宝石槽和发射器。关卡可设置高亮强度并采用西 1 的 0.7 预设，试玩时原生聚光和蓝边随供电触发。调整分屏起点或尺寸时提示受影响的供电物件。
- 修复西 1 等原版关卡省略分屏尺寸时的读取，使用原生 6×6。新建分屏显式保存 16×16。
- 三棱镜属性增加变色范围卡片，可切换默认四色、组合原生波段或恢复原版预设。
- 地板和墙面可分别设置默认色，并用矩形在同一面局部刷色。地形颜色随区域复制及旋转，并写入试玩的可见地砖和墙面。支持染色的原版地形模型可从物件属性调整。

## 验证

- 本机原版 Steam Build `26466613` 通过 390 项通用和原生回归。检查覆盖时序和高亮字段读写、三棱镜配置、地形碰撞保留及配色旋转。
- Windows 编辑器检查了标签拖出、跨窗口剪贴板、矩形刷色和保存。临时试玩对照了分屏移动前后的宝石供电、单场景 `beam_rooms`、两组三棱镜颜色轮转，以及地板、墙面和局部染色。时序数值经原生关卡包回读验证。
- 程序未签名。原生机制使用隔离临时试玩检查。[操作与验收步骤](https://github.com/chenyehuan1234/sinking-star-editor/blob/v0.10.0/docs/V09-ACCEPTANCE.md)
