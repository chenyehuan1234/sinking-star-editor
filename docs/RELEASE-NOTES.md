# v0.7.11-beta.1

新增自由停靠工作区，工程格式继续兼容 v3。

- 22 类面板可独立打开，包括关卡、场景物件、主画布、素材与快捷槽、属性、游戏镜头、原生区域、循环与边界、放置设置、分组、阵列、机关检查与关系、显示、区域复制、组合库、恢复、原版目录、工程检查、快捷键、工作区设置和指南。
- 拖动标题到四边拆分、到中间合并标签，可重排标签；支持窗口内浮动、移动、缩放、重新停靠、最大化和关闭。标题过长时支持滚轮横向浏览，尺寸保护避免操作按钮挤掉标题。
- 提供标准、地形编辑和机关设计预设，命名布局保存、布局锁定、默认恢复和重启恢复；关闭面板后保留原停靠位置及尺寸。Tab 默认最大化主画布／恢复，原有自定义键位优先。
- 原版目录、操作设置和全局指南可从窗口右上角转为停靠页；目录筛选和指南检索得到保留。F1／Ctrl+F 仍打开完整全局指南，停靠阅读时不会误触场景删除。
- 停靠复用原内容节点和 WebGL 画布，布局调整不进入工程和撤销历史，不发起整关原生预览。隐藏页面暂停跟随画布重复渲染，原版目录和操作设置复用稳定组件；素材、目录与属性滚动在隐藏、拆分、缩放后恢复。
- 内置指南、命令搜索、操作设置与 README 已同步。布局数据仅存本机；浮动目前限编辑器窗口内部，不是独立系统窗口。

检查：类型检查、通用测试和构建通过。无原游戏环境 117 项通过、72 项原生测试跳过；Steam Build 26249670 的 189 项测试通过。新增 53 项实际界面自动检查，既有 24 项浏览记忆、13 项放置手势、36 项快捷槽／地形／取景及 16 项界面回归通过，共 142 项。公开示例、空白关与原版相机读取构建检查通过，原游戏源包和程序保持不变。

提供 Windows x64 安装版、免安装 ZIP 及 SHA-256 校验，程序未签名。自动界面检查和页面缩放不等同于人工手感、Windows DPI、安装卸载或游戏内验收；本轮未启动游戏、部署副本或处理用户存档。

# v0.7.10-beta.1

新增八个快捷素材槽、精确地形矩形和单场景相机取景；工程格式继续兼容 v3。

- 素材栏提供可折叠的 8 个槽位，1–8 启用、Ctrl+1–8 更新。保存单个玩法物件的完整原生配置，拖入只绑定；支持改名和清空。快照冻结，副本分配独立 ID、频道和角色身份，外部引用清除后提示重新关联。
- 槽位保存在本机独立文件，按原生源包、程序与版本隔离，写入原子替换并保留备份。锁定高度按工程、关卡及槽位分别记忆；快速切换会刷新刚修改的摆放习惯。失败或损坏槽位显示原因。
- 地形支持拖动矩形与固定尺寸，显示工作面、起点和长×宽×厚；三种平面可反向展开，厚度 1–128 层，单笔最多 4,096 格。整片预览与提交共用格子结果，一次撤销完整恢复。大地图仍限定 XY、一层地图格。
- 自由视角可直接保存为单场景游戏镜头，保留原自由编辑视角并支持一步撤销。镜头编辑增加 16:9、4:3、21:9 和跟随视口的构图留边；留边不接受镜头操作，比例不改变游戏分辨率。分屏、总览、翻转与动态引用保留原生限制。
- 新建空白关扩建出框时提供重新取景／忽略，不自动覆盖构图。框住范围保留隐藏玩法物件，排除背景与辅助物；新增命令同步到改键、命令检索与离线指南。

检查：类型检查与构建通过；无游戏环境 109 项通过、72 项原生测试跳过；Steam Build 26249670 的 181 项测试全部通过。新增 36 项界面自动检查、既有 24 项浏览记忆、13 项放置手势及 16 项界面回归通过，共 89 项。六组公开示例、空白关和三组原版相机读取构建检查通过，原包与程序校验保持不变。

Windows x64 安装版、免安装 ZIP 与 SHA-256 校验均提供，程序未签名。自动界面及页面缩放不等同于人工手感、Windows DPI、安装卸载或游戏内验收。本轮未启动游戏、部署副本或切换用户存档；原生机制、实际画幅与通关由用户在专用测试战役中检查。
