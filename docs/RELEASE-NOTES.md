# v0.7.9-beta.2

修正地形与机关切换、中键取样、虚像材质和自动工作面；工程格式保持 v3。

- 默认中键单击取样：物件进入连续放置，地形回到地形工具并记录高度；超过拖动阈值后只导航，松手不取样。鼠标设置可关闭单击取样；游戏镜头编辑的固定手势保留。
- “地形／机关”直接切换工具并恢复各自上次配置，不再只改变吸附参数。相同物件的原生取样与预览复用缓存，快速换工具或切关时忽略过期结果。
- 自动工作面始终按镜头朝向选择；俯视命中地形侧边也保持水平展开。手动 XY/XZ/YZ 保留指定方向，按下后固定整笔工作面。
- 虚像保留原生材质的世界 UV、着色、配饰遮罩和透明裁切；透明度与裁切阈值同步，关闭透明预览深度写入并避免双面重复绘制。矩形模型更换后清理旧预览，实例化预览使用各自的世界坐标。
- 更新离线指南、当前鼠标配置显示和用户验收步骤。

自动检查：类型检查通过；无游戏环境 96 项通过、70 项原生测试跳过；Steam Build 26249670 的 166 项回归全部通过。实际编辑界面的 13 项放置手势检查及 16 项既有界面回归通过，覆盖中键单击／拖动、切换缓存、水平矩形、取消及过期取样；近景截图用于核对虚像。公开示例、空白关及原生区域相机读取和构建检查通过，原包与程序保持不变。

已生成 Windows x64 安装版、免安装 ZIP 与 SHA-256 校验。自动界面及数据检查不等同于用户手感、Windows DPI、安装卸载或游戏内机制验收；本轮未启动游戏、部署测试副本或处理存档。

# v0.7.9-beta.1

操作效率与编辑可靠性升级；工程继续兼容版本 3。

- 原生预览与重型校验移到后台线程，缓存解析模板；常规提交返回实体与地形块差量，旧修订不会覆盖新场景。
- 拖动、地形笔画和微移仅做本地预览，提交后保留当前位置；取消、失焦及打开指南／命令窗口恢复未提交动作。属性提交去掉重复预览，保存和试玩等待已提交修改。
- 物件级隐藏、锁定、隔离、重叠选择；场景、机关和分组列表虚拟化。编辑分组可保存、改名、增减成员、独立复制及撤销，不改变原生存在组、角色控制或构建修订。
- 普通频道使用汇总节点、统一色标；有方向的对象引用标出字段及失效目标，可临时显示关联对象。保留 64 位频道精度，特殊开关与怪物门不纳入普通控制图。
- 局部矩形／连续面拉伸：先选裸露面，再拖法线或输入正负层数；保留孔洞、4,096 格及 128 层限制。
- 长按方向键微移：300ms 后每 80ms 重复，全部释放合为一步撤销；同类原版配置批量切换；玩法阵列最多新增 2,000 个物件，默认副本内部关联独立。
- Ctrl+Shift+P 搜索执行命令，Ctrl+F 继续检索离线指南；保留旧自定义键位。更新指南、README 与格式说明。

检查：从暂存源码导出的干净副本独立安装依赖，类型检查和构建通过；通用测试 93 通过、70 项原生测试明确跳过；连接 Steam Build 26249670 时 163 项自动测试全部通过。六组公开示例及三组原版区域相机读取、保存构建回归通过，未修改相机记录逐字节保留，原包及游戏程序校验未变化。

独立界面脚本通过 16 项检查，覆盖分组保存／撤销、锁定、属性单次预览、命令检索及两种分辨率与 150% 页面缩放。100／1,000／5,000 个简化物件和原版多高度关的预热性能基准见 [性能记录](PERFORMANCE.md)，不将代理物件、自动界面或页面缩放当作全机型、人工手感、Windows DPI 或游戏内验收。

安装版和 ZIP 均为 Windows x64，未签名，需要安装原游戏。未启动游戏、部署副本或切换用户存档。游戏内加载、机制操作与通关，以及安装／卸载仍由用户验收。完整循环大地图、多层世界与解锁进度留待 v0.8。
