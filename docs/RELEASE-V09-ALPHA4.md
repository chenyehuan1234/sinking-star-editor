# v0.9.0-alpha.4：统一镜头与矩形分屏（仅本地）

- 游戏镜头与分层镜头合并为镜头面板；旧浮动／标签布局迁入，保留已有镜头位置，布局菜单不再重复入口。主列表默认玩法镜头，原版控制区域默认折叠并解释用途。
- 规则分屏在自由画布默认显示边界与规划外框。自动按设计范围铺满，可手动改横纵屏数；规划元数据随工程保存，不写入原生字段，不改变试玩存档兼容身份。
- 画一屏大小：正交俯视拖矩形，预览并确认起点与宽高。画循环边界：同样流程，只改 X/Y 并保留 Z 与循环开关。确认一步撤销，取消／失焦／越界无提交，结束恢复原视角。
- 原游戏带俯角的 3D 透视会有遮挡；分屏格数不等于画面所有格子都可见。

范围：原版分屏与区域数据继续保留；手动屏数只定义编辑规划范围，不冒充游戏边界。循环仍受原有自定义范围校验限制，超限显示原因。未改原安装或正式存档，不关闭现有窗口，不上传 GitHub。
