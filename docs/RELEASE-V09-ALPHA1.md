# v0.9.0-alpha.1：统一完整世界工作台

完整原版大世界和小关现在使用同一套停靠界面、素材、属性和编辑工具。地下、地表、天空属于同一份 overworld；画布按视野与 Z 范围加载，不再要求进入另一套分区界面。

- 完整登记 204,988 条原生记录、920 个入口、993 个小关与辅助场景。原生区域作为初始关卡分组，允许自行改名、排序、归组和新建；组织变化不改变游戏进度或原生相机区域。
- 远处显示轻量概览，放大后加载细节。支持任意正负 Z 范围，独立于放置高度；原始循环边界、跨层连接和未知记录保留。
- 新建、复制、导入小关，放置三维入口并关联目标。删除场景先检查入口和其他原生依赖；已处理的场景与入口作为一步修改撤销。
- 新 v5 工程保存原生基础引用、完整场景目录及有序修改。v4 另存升级保留原文件，v3 继续可读。全世界构建保留原记录，单关／关卡组使用现有独立范围构建。
- 修复门闸活动门体颜色：独立读写 force_field_color 与亮度，不再只修底座 tint。新素材配置携带两种颜色；旧工程不自动改写，可手动恢复素材颜色。
- 中键保持位置松手才取样；任何移动均只导航。原生地形材质显示切关后保持。

## 自动验证与范围

类型检查通过；通用测试189项通过、104项需原游戏而明确跳过；本机原生集成293项全部通过。统一工作台19项、入口往返9项、中键与材质21项、门闸及既有交互159项自动界面检查通过。性能结果记录于本仓库性能文档。覆盖旧 v4 顺序迁移、未修改包字节一致、分组不影响原生内容、新场景资源、XYZ 入口、中文导出、范围构建出口重映射及运行中部署拦截。

界面检查为隔离的 Electron 自动窗口，覆盖 1366×768、1920×1080 和 125% 页面缩放；不等同于完整 Windows 多显示器 DPI 检查。试玩按钮使用模拟启动，没有执行游戏内验收，也没有修改正式存档或原安装。

世界数据进程基准：首次索引约 2 秒，三个代表性细节窗口首次 149–255ms、相同窗口缓存命中 P95 约 5–7ms；数据进程 RSS 约 752MB，不包含 Electron 与 GPU。5000 个简化物件的选择 P95 约31ms、拖动反馈约23ms；真实复杂模型和其他电脑需另测。见 [性能记录](PERFORMANCE.md)。

## 限制与使用

这是测试版。原生关卡序列等尚未开放编辑的依赖会阻止删除相关场景；部分原生区域交界仍待确认。未知机制保留，不据此推断游戏行为。完整世界循环、跨层、解锁进度、门体游戏内颜色和本版人工操作手感仍待实测，步骤见 [v0.9 验收](V09-ACCEPTANCE.md)。

下载 Windows x64 安装程序或完整 ZIP，并核对 SHA256SUMS.txt。程序未签名，不包含原游戏资源。先保存已有工程，再自行退出旧编辑器并启动新版；首次连接选择包含 sinking_star.exe 的文件夹。隔离试玩仅对已检查的程序版本开放，不要手动启动旧共享存档副本。

范围外有效引用保留目标类型和坐标并可定位；世界频道成员列表只反映当前加载范围，暂禁用全世界频道批量合并，避免误改。
