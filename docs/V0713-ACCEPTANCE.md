# v0.7.13-beta.1 验收与限制

## 已实现

- 素材栏地形分类中的地面／墙体卡；默认按命中面确定矩形工作面，收藏及最近使用入口。
- 中键直接取样；移除取样按钮、顶部地形与擦除按钮。地形左拖添加、命中地形右拖擦除、空白处右拖旋转；擦除只作用于地形。
- 固定网格开关移到导航栏，保留用户开关偏好，不恢复鼠标跟随网格。
- 六轴观察、最近轴向、点选地形面对齐、X/Y/Z 角度旋转、正交／透视及返回上一视角。导航命令可绑定快捷键。
- 整体浅色主题及简洁模式，分别保存布局；旧布局与偏好保留。
- GitHub 版本检测、跳过版本、关闭自动检查、校验下载、保存后安装／打开 ZIP 目录。
- 新保存工程记录原生结构和依赖指纹；较新游戏版本依赖一致时可适配为副本，原文件保留。

## 未完成和验证边界

- 成就隔离按用户要求不处理，保留原有试玩启动流程。
- 当前仅允许可证明依赖未改变的跨版本适配；旧工程缺少依赖记录、结构或模板变化时仍被阻止，提供只读工程目录与兼容报告，不强行渲染不兼容的原生场景；通用迁移及逐对象修复不在本版支持范围。快捷槽与组合仍按来源隔离。
- 方向立方体提供六面与角部斜视导航；游戏镜头编辑继续使用原生参数和既有手势，不允许把正交、倒置或翻滚的编辑视角写回。
- 当前游戏已是 Build 26466613；与此前 26249670 相比，字段结构与多个原版模板有变化，不能把版本递增当作兼容证明。
- 更新下载与覆盖安装逻辑已接入，尚未执行真实覆盖安装端到端验收。不会为测试关闭用户编辑器。
- Windows 测试版发布时明确标注兼容边界和验证范围。启动脚本优先读取本地 v0.7.13 包，不自动关闭或替换正在运行的旧编辑器。

## 用户检查步骤

1. 新建空白工程，素材栏选地形。中键取样，左拖添加、右拖擦除，检查虚像及一步撤销。
2. 在三个工作面上测试；右键单击退出，空白处右拖旋转。Esc、失焦和视口外释放应取消。
3. 导航栏开启固定网格，切换浅色主题，检查地形边缘与格线；网格不应随鼠标变化。
4. 点击 ±X／±Y／±Z，对准地形面、按轴旋转、切回透视；操作不应修改工程游戏镜头。
5. 切换简洁／完整，检查自定义布局、物件选择和未保存工程均保留。
6. 更新窗口关闭自动检查，再手动检查；离线不应影响编辑。安装测试需先保存工程，另行执行。

自动测试、界面自动检查、游戏内实测分别记录；本轮没有启动原游戏或修改原存档。
